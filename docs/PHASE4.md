# Interface experimental
Painel, pesquisa PubMed, indexação e busca semântica, biblioteca de referências no localStorage e configurações informativas. Interface local apenas, porta 3000. O proxy Next.js guarda a chave do backend no servidor, valida origem e limita campos; não é autenticação de usuário. Não exponha à rede. Use http://localhost:3000 (origem configurável). A biblioteca não sincroniza nem deve conter dados clínicos. Fases 2 e 3: CI aprovado, Docker integrado e custos reais pendentes. RAG ainda recupera títulos, sem geração clínica. Dependências npm ainda sem lockfile; gerar e revisar antes de produção.
